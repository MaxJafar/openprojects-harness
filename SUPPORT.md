# Support

OpenProjects is community-maintained software provided without warranty or a
support-level agreement.

- Use repository issues for reproducible bugs and narrowly scoped feature
  requests after removing all private data.
- Use repository discussions, when enabled, for deployment questions and design
  exploration.
- Include the OpenProjects version, operating system, Node.js version, redacted
  configuration shape, and minimal reproduction.
- Do not attach databases, tokens, chats, audio, model artifacts, or unredacted
  logs.

Security vulnerabilities and conduct reports must not be filed publicly. Use
the private process in [SECURITY.md](./SECURITY.md#reporting-a-vulnerability).

Commercial support, managed hosting, and deployment certification are not part
of this repository unless a separate provider states otherwise.
